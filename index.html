Java程序从main方法启动的执行流程？

编译过程：

  1. 词法/语法分析：javac扫描源码，校验语法
  2. 语义分析：校验逻辑合法性
  3. 生成字节码：转换为JVM指令
  4. 输出.class文件
变量与常量（final）区别？局部/成员变量作用域？

变量 vs 常量：

  • 变量：值可变
  • final常量：赋值后不可变

作用域：

  • 局部变量：方法/代码块内部，必须手动初始化
  • 成员变量：类内部，有默认值

类型转换规则？精度丢失场景？

规则：

  • 自动转换：小→大类型
  • 强制转换：大→小类型

精度丢失：

  • 浮点转整数（丢小数）
  • 大整数转小整数（可能溢出）
  • double转float（精度降）
int i = 100; long l = i; // 自动 double d = 100.04; long l2 = (long)d; // 强制，丢小数
